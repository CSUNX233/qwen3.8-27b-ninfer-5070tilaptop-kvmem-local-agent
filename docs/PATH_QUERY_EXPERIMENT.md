## 改动与回退

`NINFER_KVMEM_QUERY_MODE` 未设置或为未知值时，保持旧查询跨度不变。

| 值 | 行为 | 用途 |
| --- | --- | --- |
| 未设置 | 最后用户消息跨度 | 默认和基线 |
| `user-tail` | 最后用户消息末 64 token | 隔离查询长度因素，尚无改善证据 |
| `latest-tool-head` | 最后用户消息之后，最新可用工具结果的前 64 token | 有局部改善证据的候选 |

出现新用户消息时，旧工具结果不再充当查询来源；没有后续工具结果就保留旧用户查询。这里只选择已有 token 行，不改 prompt、position、文件名、工具参数、KV 格式或数值内核，也不执行静默路径替换。

在独立候选进程启动前设置环境变量可测试；清除变量并重启恢复旧策略。既有 KV 查询缓存及重评分通路可能因此活跃，不能据源码未新增固定缓冲就承诺显存和耗时完全不变。尚未做独立峰值显存及持续长稳测试。
