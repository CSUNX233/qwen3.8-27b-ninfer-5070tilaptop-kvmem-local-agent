## 原型阶段记录（安装前）

日期：2026-10-21。此轮在[前一轮惩罚诊断](SHORT_TASK_SAMPLING_DIAGNOSIS.md)基础上，实际尝试只对回答生成的 token 施加 presence penalty，保留回答内部强度 1.0。原始 carry-over 默认保留，日常未替换。

结论：本夹具的短任务收益与完全取消回答惩罚相同；局部计数与抽样验证了新作用范围确实生效，但非 Huihui GSQ 仍有一例误调用。代码、重复字段 JSON 和 98K 续接通过，不能据此承诺总体质量提升或所有循环已修复。

脱敏逐项数据：[answer-scope-verification.json](../benchmarks/evidence/long-context-tool-loop/answer-scope-verification.json)；可审阅的最小语义补丁：[answer-scope-prototype.patch](../benchmarks/evidence/long-context-tool-loop/answer-scope-prototype.patch)。补丁是私有候选行为的抽取，不包含日志探针，也没有应用到正式源码。

## 实现和构建边界

以未安装 FP16 GDN 候选 `153f562272c10e603e84cfd9d5bbf9ceb296270139dad52708ac96f8ecd4a808` 为基底，生成私有 Host 覆盖：当前 `update_sampling` 的唯一运行时调用点是已提交的思考闭合边界，试验开关 `NINFER_EXPERIMENTAL_ANSWER_PENALTY_RESET=1` 在此清零当前 lane 的计数。默认关闭。回答的 presence 仍为 1.0，frequency 仍为 0；没有禁用工具、修改思考采样或清除模型上下文。

清零使用原有 248077 个 I32 的数组，共 992308 字节，在相同 CUDA stream 上排在下一轮抽样之前。没有新增 GPU 常驻 buffer 或重编 CUDA 内核。复用已有 MTP 思考边界屏障；回答开始后普通和 MTP 路径继续正常累计计数。计数数组同时服务 presence/frequency，新作用范围会同时影响二者，但本轮实模 frequency 均为零，不构成非零 frequency 的完整验收。

候选 SHA-256：`4fa15adabfaaa0bcabcfcdf4db470d865852daaacda90fe1a221356a83f4d427`。三个 Host 覆盖单元包含试验行为与可选日志，其余对象和原静态库复用；非干净全量构建。模型权重、原模板、NVFP4、FP16 GDN、xhigh、MTP3/ngram15、262144 上限、39168 页池 token 容量及检索预算保留。正式源码快照中 1699 个文件核对未变。

这是私有进程开关原型。通用 sampling-update 语义、正式每请求 API、并发多 lane 和其他投机后端尚未实现或验收，不能直接当作公开部署参数。

## 同题十 seed 对照

| 模型 | 原跨阶段计数，presence=1 | 回答 presence=0 | 回答独立计数，presence=1 |
| --- | --- | --- | --- |
| Huihui Swift 1.5 | 9/10 | 10/10 | 10/10 |
| 非 Huihui GSQ-RCO | 7/10 | 9/10 | 9/10 |

两个模型均为 IQ3_XXS，任务为同一道 818-token 合成题，seed 20359323–20359332。原跨阶段与零惩罚使用前轮 GDN 候选的记录，实际模型及引擎清单均已核对；独立计数使用本轮候选。原跨阶段对比独立计数的请求逐项相同，各模型十个思考文本前后逐字相同。不是十类任务，不能外推总体准确率。

Huihui 两次额外热缓存重复均通过。GSQ 额外重复中 `short-0` 仍失败、`short-6` 通过，不混入十 seed 主表。GSQ 剩余失败的首回答位置，工具标记原始 logit 已最高，与前轮无回答惩罚的失败一致；独立计数没有解决这部分。

## 计数与采样的直接验证

- 开关关闭时，两个无投机请求与前轮逐字一致（忽略调用 id），16 组完整 logits/计数数组逐字相同。
- 同样两个无投机请求，原跨阶段计数为 0/2，通过独立计数变为 2/2；思考及首回答位置完整原始 logits 相同，变化在惩罚计数与后续轨迹。
- 普通解码与 MTP 四个请求各捕获回答前八个位置，共32步。每步完整词表计数与“仅已提交回答 token”独立重建一致，首步全部为零；presence 始终为1。32/32个 target 选择与独立CPU FP64重算吻合。这验证了给定 logits 后的计数与抽样，不是独立模型前向证明。

没有通过修改解析器把失败改判成功，也没有只把思考中的正确答案计作任务完成。

## 功能、重复输出及边界

功能组为六类直接任务和三次显式工具调用、三次结果回答，包含合法重复读取与不可信工具文字：

| 实际模型 | 原跨阶段计数 | 回答无惩罚 | 回答独立计数 |
| --- | --- | --- | --- |
| huihui | 12/12 | 12/12 | 12/12 |
| gsq | 11/12 | 11/12 | 11/12 |

本轮保留的功能失败项：`gsq/carry_over/functional-escaping`, `gsq/no_answer_penalty/functional-escaping`, `gsq/answer_only/functional-escaping`。具体评分和输出 hash 保留在证据中，不把未通过项略去；跨请求的工具历史包含真实前一轮回答，不能假设所有策略的后续请求仍完全相同。

GSQ 三种策略均在同一条引号抄写题失败，引号内多出一个空格；该题思考和正文三组逐字相同，没有发现独立计数新增这项失败。

较长生成另测48个 Python 函数（AST检查名字、参数和全部公式）、96行必须保留重复字段的JSON（逐项精确比较）及中文八段正文：

| 模型 / 策略 | 代码及 JSON | 正文结构检查 |
| --- | --- | --- |
| huihui / default | 2/2 | 1/1 |
| huihui / reset | 2/2 | 1/1 |
| huihui / zero | 2/2 | 1/1 |
| gsq / default | 2/2 | 1/1 |
| gsq / reset | 2/2 | 1/1 |
| gsq / zero | 2/2 | 1/1 |

`default/reset/zero` 分别表示原跨阶段计数、回答独立计数、回答无惩罚。正文检查仅覆盖自然结束、八段、长度、无整行长文本重复和无实际工具调用；人工阅读仍发现事实性错误，包括部分输出对频率惩罚或温度作用的错误解释。不能将结构通过写作内容全部正确或整体写作质量改善。

Huihui 新版正文的原策略与独立计数补测分别在独立服务启动后执行，而零惩罚正文在代码和 JSON 之后执行；它们仅用于结构健壮性观察，不构成受控的正文质量或速度排序。人工阅读结论及正文 hash 见证据 `prose_manual_review`。

最初约2400字正文题，Huihui 原策略与独立计数均在10000-token额度用尽时仍处于思考中，正文为空，两次逐字相同，干预尚未触发。保留该失败；随后改用不设字数目标的新版题补测，不将前后不同题当作修复对照。两种正文夹具与全部请求体均私有保留。

另做不思考、强制64-token思考闭合、总输出8-token截断三类边界，每类原策略/独立计数各一次。它们只检验状态与协议，不计任务质量；实际核对见证据 `boundary_diagnostics`。缩短额度不用于主质量对照。

不思考请求与思考中截断请求没有触发该重置；两策略输出除随机调用 id 外一致。强制闭合时首回答计数由包含思考的非零数组变为全零，但两策略仍误调用；不思考两组也仍误调用。它们没有被记为任务成功。最初比较脚本因随机调用 id 不同而断言失败，定向核对后仅排除该非语义字段，使用原有六次记录重新验证，没有重跑或修改生成结果。

## 98K 长历史续接

Huihui 独立计数候选，冷输入98592 tokens，最终十项均正确。三次显式工具调用及三次结果回答全部通过，包含再次合法读取同一记录，合计7/7。六次续接缓存命中 100329–100819 tokens，整轮约 1.02–1.37 秒；冷主任务约 252.37 秒。

没有出现循环、页池耗尽或CUDA异常。这是合成召回和工具组；没有满256K、真实dsh/浏览器链路或受控性能结论。没有证明任意长正文均无重复。
